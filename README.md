# dp — Website

پروتوتایپ کامل فروشگاه پیراهن‌تنبان مردانه dp، با طراحی سفید و سبز رویال، کالکشن‌های داستان‌محور و مسیر سفارش آزمایشی.

## اجرای محلی

در پوشه پروژه اجرا کنید:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

سپس `http://127.0.0.1:8000/` را باز کنید. نصب وابستگی یا build لازم نیست.

## امکانات

- مجموعه‌ها، دسته‌بندی، جست‌وجو، فیلتر و مرتب‌سازی.
- عکس مستقل محصول و نمایش تن‌خور با هاور، فوکوس یا کنترل لمس.
- جزئیات محصول، راهنمای اندازه، انتخاب سایز و تعداد و نشان‌کردن کالا.
- سبد، ثبت درخواست، رسید و پیگیری نمایشی.
- مجله، درباره برند و راهنمای سفارش.
- نمایش تطبیقی موبایل، تبلت و دسکتاپ.

این نسخه سفارش یا پرداخت واقعی انجام نمی‌دهد. محصولات، قیمت‌ها و اندازه‌ها نمونه‌اند؛ تصاویر مفهومی و تولیدشده با هوش مصنوعی هستند. داده‌های آزمایشی در مرورگر ذخیره می‌شوند.

راهنمای کامل و بررسی‌های انجام‌شده در [README-nayab.md](README-nayab.md) و جزئیات تصاویر در [IMAGE-PROMPTS.md](assets/nayab/IMAGE-PROMPTS.md) قرار دارند. مجوز استفاده تجاری فونت Doran باید توسط صاحب پروژه بررسی شود.

نسخه مرجع قبلی در `kalu-reference.html` حفظ شده است. ZIP خروجی فقط محلی نگه‌داری می‌شود و جزو سورس ریپازیتوری نیست.

## شناسنامه محصول (پروتوتایپ)

مسیر `#/verify` برای ورود شناسه و نمایش شناسنامه یک دست لباس نمونه است. شناسه آزمایشی `DP-7K4M-92QX` به مدل `DP-101`، رنگ عاجی، سایز M متصل است. QR واقعی با کتابخانه MIT از kazuhikoarase/qrcode-generator به صورت محلی ساخته می‌شود و به نشانی جاری سایت اشاره دارد. حروف کوچک و فاصله یا خط تیره پذیرفته می‌شوند.

این نسخه پایگاه داده و احراز اصالت واقعی ندارد؛ شناسه نمونه در سورس عمومی است. ثبت شناسه اثبات اصالت لباس فیزیکی نیست. کد مخفی، شمارنده اسکن و وضعیت قبلاً بررسی‌شده عمداً وجود ندارند. برای استفاده واقعی باید ثبت و استعلام از داده‌های معتبر سرور انجام شوند. کدهای داخلی NY برای سازگاری سبدهای قبلی حفظ شده‌اند؛ کد مدل نمایشی DP است.
